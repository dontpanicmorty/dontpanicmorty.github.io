# dontpanicmorty.github.io

Maurice Allen's resume and projects, published with GitHub Pages at https://dontpanicmorty.github.io.

Plain HTML and CSS, no build step: `index.html`, `styles.css` and `favicon.svg`. `.nojekyll` tells GitHub Pages
to serve the files as they are.

Preview locally: `python3 -m http.server 8000`, then open http://localhost:8000.
